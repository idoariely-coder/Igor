## העלאה לשרת (פעם אחת, בערך 15 דקות)

צריך שני דברים:
1. **מפתח Claude API**: נכנסים ל-https://console.anthropic.com, פותחים חשבון, מוסיפים אמצעי תשלום ויוצרים מפתח (API Key).
2. **שרת קטן**: ההמלצה היא [Railway](https://railway.app), שהוא פשוט ונותן כתובת https מאובטחת.

### העלאה ל-Railway
1. מעלים את התיקייה הזו ל-GitHub (מאגר פרטי).
2. ב-Railway בוחרים **New Project ← Deploy from GitHub repo** ובוחרים את המאגר. Railway מזהה את ה-`Dockerfile` לבד.
3. בלשונית **Variables** מוסיפים:
   - `ANTHROPIC_API_KEY` = המפתח מהשלב הקודם
   - `DATA_DIR` = `/data`
4. בהגדרות השירות מוסיפים **Volume** עם Mount path `/data`. שם נשמרים מסד הנתונים והצילומים, כך שהם לא נמחקים בעדכון.
5. בלשונית **Settings ← Networking** לוחצים **Generate Domain** ומקבלים כתובת כמו `igor-xxx.up.railway.app`.

אפשר להשתמש גם בכל שרת אחר שמריץ Docker, למשל Render (עם Persistent Disk) או Fly.io.

### התקנה באייפון ובאייפד
1. פותחים את הכתובת ב**ספארי**.
2. בפעם הראשונה מגדירים את שם התלמידה, קוד של 4 ספרות לתלמידה וקוד להורה.
3. לוחצים על כפתור השיתוף ← **הוספה למסך הבית**. מעכשיו איגור נפתח כמו אפליקציה רגילה.
4. בתוך האפליקציה, ב**הגדרות ← הפעלת התראות**, מפעילים את התזכורת היומית.

אותה כתובת עובדת בכל המכשירים. המידע נשמר בשרת, כך שאפשר להתחיל באייפון ולהמשיך באייפד.

## עלויות (הערכה)
- **Railway**: בערך 5$ לחודש.
- **Claude API**: משלמים לפי שימוש. הודעה רגילה בצ׳אט עולה בערך סנט עד שלושה, וצילום מוסיף קצת. בשימוש יומי רגיל ההערכה היא כ-10–40$ לחודש, תלוי בכמות. אפשר להגדיר תקרת הוצאה ב-console.anthropic.com תחת Limits.

## הרצה מקומית (למפתחים)
```bash
npm install
cp .env.example .env      # ולשים בו את המפתח
npm run build && npm start   # http://localhost:3000
# או לפיתוח: npm run dev    # http://localhost:5173
```
בלי מפתח האפליקציה עולה ב**מצב הדגמה**: הכל עובד, אבל איגור עונה תשובות לדוגמה.

## מבנה
- `shared/curriculum.js`: תוכנית הלימודים (פרקים, נושאים, מיומנויות). כאן מעדכנים אם המורה מלמד/ת בסדר אחר או מוסיף/ה נושא.
- `server/ai.js`: האישיות של איגור וכללי ההוראה (`IGOR_CORE`), יצירת תרגילים, בדיקה וניתוח צילומים.
- `server/learning.js`: שליטה בנושא, חזרה מרווחת, תוכנית יומית ותוכנית הכנה למבחן.
- `server/index.js`: ה-API. `client/src`: האפליקציה (React).

## פרטיות
- כל המידע (שיחות, צילומים, ציונים) נשמר רק בשרת שלכם. הכניסה מוגנת בקוד אישי.
- צילומים ושאלות נשלחים ל-Claude API לצורך מענה. לפי מדיניות Anthropic, מידע שעובר דרך ה-API לא משמש לאימון מודלים.
- ההורה רואה סטטיסטיקה וכותרות של שיחות, אבל לא את התוכן שלהן.
- איגור מוגדר להתמקד במתמטיקה. אם עולה מצוקה רגשית, הוא מפנה למבוגר, ליועצת או לער״ן (1201).
